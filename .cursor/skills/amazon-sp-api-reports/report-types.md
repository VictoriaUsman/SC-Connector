## Sales & Traffic Reports

| Report Type | Description | Schedule Support |
|-------------|-------------|-----------------|
| `GET_SALES_AND_TRAFFIC_REPORT` | Sales and traffic (Brand Analytics) | Yes |

**Note:** This report requires Brand Registry enrollment. Request body must include `reportOptions`:
```json
{
  "reportType": "GET_SALES_AND_TRAFFIC_REPORT",
  "marketplaceIds": ["ATVPDKIKX0DER"],
  "reportOptions": {
    "dateGranularity": "DAY",
    "asinGranularity": "CHILD"
  },
  "dataStartTime": "2026-03-01",
  "dataEndTime": "2026-03-15"
}
```

## Date Parameters

- Most reports accept `dataStartTime` and `dataEndTime` (ISO 8601).
- Settlement reports are auto-generated by Amazon; use `GET /reports` with `reportTypes` filter to list them.
- Brand Analytics reports use `reportPeriod` in `reportOptions` instead of date range.

## Output Formats

- Most reports return tab-delimited (TSV) flat files.
- Some return XML (report types with `XML` in the name).
- **JSON reports**: Sales & Traffic, Brand Analytics, and Ledger reports return nested JSON. These are automatically converted to flat TSV by `functions/shared/report_converter.py` before uploading to Drive. The JSON report types are listed in `_SP_API_JSON_REPORTS` (in `drive_client.py`) and `_JSON_REPORT_ARRAY_KEYS` (in `report_converter.py`).
- Reports may be GZIP compressed; check `compressionAlgorithm` in the document response.
